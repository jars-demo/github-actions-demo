## [Unreleased]

### Added

- Pulse, a tiny TypeScript status API with an OpenAPI contract, tests and a non-root image.
- Workflows: backend CI with a matrix, a nightly run through a reusable workflow, releases on
  tags, container build and publish, a GitHub Pages deploy, and frontend checks.
- A composite setup action and Dependabot with a 14-day cooldown.
- Twelve workshop chapters, a facilitator guide and the workshop site.
- Tests that enforce the pipeline's own rules: pinned actions and read-only default permissions.
